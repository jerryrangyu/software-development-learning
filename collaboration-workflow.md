
# Software Development Team Collaboration

## 1. Team Roles

- Product Manager: Defines product goals and requirements.
- UI/UX Designer: Designs the user interface and user experience.
- Software Developer: Writes and maintains code.
- QA Engineer: Tests software and identifies bugs.
- DevOps Engineer: Manages deployment and infrastructure.

## 2. Why Do Teams Use Branches?

Branches allow developers to work independently
without directly changing the main branch.

This reduces conflicts and protects stable code.

## 3. Why Do Teams Use Pull Requests?

Pull Requests allow developers to propose changes
and receive feedback before merging.

## 4. Code Review

Team members review proposed changes to identify
bugs, improve readability, and maintain code quality.

## 5. Typical Collaboration Workflow

1. Create a feature branch.
2. Modify project files.
3. Stage and commit changes.
4. Push the branch to GitHub.
5. Create a Pull Request.
6. Review the proposed changes.
7. Merge the branch into main.
