
# Git and GitHub Basics

## 1. Repository
A repository is a place where project files
and their version history are stored.

## 2. Commit
A commit records changes made to project files.
Each commit has a unique identifier and message.

## 3. Branch
A branch allows developers to work on different
features without directly changing the main branch.

## 4. Merge
Merge combines changes from one branch into
another branch.

## 5. Pull Request (PR)
A Pull Request allows developers to propose
changes and request that their code be merged
into the main branch.

## 6. Code Review
Code review is the process of checking another
developer's changes before merging them.

## 7. Common Git Commands

- git init: Initialize a repository.
- git add: Stage changes.
- git commit: Save changes.
- git push: Upload commits.
- git pull: Download and integrate remote changes.
- git branch: Manage branches.
- git merge: Combine branches.
- git status: Check repository status.
- git log: View commit history.
