
# Software Development Process

## 1. Software Development Lifecycle (SDLC)

Software development usually includes five major stages:

1. Requirements: Identify what users need.
2. Design: Plan the software structure and features.
3. Development: Write and implement the code.
4. Testing: Find bugs and verify functionality.
5. Deployment: Release the software to users.

## 2. Waterfall Development

Waterfall is a traditional development approach.
Each stage is generally completed before moving
to the next stage.

Advantages:
- Clear structure and documentation.
- Easier to plan deadlines and budgets.
- Suitable for projects with stable requirements.

Disadvantages:
- Difficult to adapt to changing requirements.
- Testing and feedback may happen relatively late.

## 3. Agile Development

Agile is an iterative development approach.
Teams develop software in smaller cycles and
continuously receive feedback.

Advantages:
- Flexible when requirements change.
- Frequent testing and feedback.
- Encourages teamwork and communication.

## 4. Scrum and Sprint

Scrum is an Agile framework.

A Sprint is a fixed period during which a team
works toward a specific development goal.

At the end of a Sprint, the team reviews its
progress and plans the next cycle.
