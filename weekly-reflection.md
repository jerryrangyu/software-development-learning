
# Week 1 Learning Reflection

## What I Learned

During the first week, I learned the basic Git and GitHub workflow.

I learned how to create a repository, track changes, and upload files to GitHub.

## Git Commands I Practiced

- git init: Initialize a local repository.
- git add: Add files to the staging area.
- git commit: Save changes in the repository.
- git push: Upload local commits to GitHub.
- git pull: Synchronize changes from GitHub, merging.
- git branch: Create and manage branches
- git switch: Switch between branches.
- git merge: Combine changes from different branches.
- git log: View commit history.

## Branches and Pull Requests

I created a feature branch called feature/collaboration-notes.

After making changes, I pushed the branch to GitHub and created Pull Request #1.

I reviewed the changes and merged the pull request into the main branch.

## Conclusion

I now understand how Git and GitHub help developers manage versions and collaborate.

I also learned that branches allow developers to work independently, while pull requests provide an opportunity to review changes before merging them into the main branch.
